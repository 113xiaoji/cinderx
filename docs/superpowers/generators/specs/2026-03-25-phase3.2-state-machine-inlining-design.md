## 概述

Phase 3.2 的目标是将递归生成器（如 `Node.__iter__`）内联为显式状态机，消除帧切换开销，实现 4-6x 性能改进。

### 设计选择

| 维度 | 选择 |
|------|------|
| 范围 | 针对性优化 TreeIter 模式 |
| 策略 | 扩展 TreeIterStateMachinePass |
| 深度 | 限制内联深度（MAX=12） |
| 表示 | 混合方式（显式指令 + 控制流） |
| 栈管理 | 调用栈（最高性能） |
| 验证 | HIR 检查 + 基准测试 |
| 实施 | 渐进式（Week 1 + Week 2） |

## 架构

### 整体流程

```
用户代码：Node.__iter__()
  ↓ HIR Builder
原始 HIR：YieldFrom, Yield
  ↓ TreeIterStateMachinePass
优化后 HIR：StateInit + 基本块序列
  ↓ Code Generator
汇编代码：无运行时调用的状态机
```

### 状态机 HIR 结构

```cpp
StateInit(stack_size=256)
BB_init:
  current = self
  phase = LEFT
BB_loop:
  Switch(phase) → BB_left, BB_yield, BB_right, BB_backtrack

BB_left:
  if (current.left) {
    StackPush(current, RIGHT)
    current = current.left
    phase = LEFT
    goto BB_loop
  } else {
    phase = YIELD
    goto BB_loop
  }

BB_yield:
  value = current.value
  phase = RIGHT
  Yield(value)  // 内联的 yield

BB_right:
  if (current.right) {
    StackPush(current, BACKTRACK)
    current = current.right
    phase = LEFT
    goto BB_loop
  } else {
    phase = BACKTRACK
    goto BB_loop
  }

BB_backtrack:
  if (StackEmpty) {
    Return()
  } else {
    current, phase = StackPop()
    goto BB_loop
  }
```

## 组件设计

### 扩展 TreeIterStateMachinePass

```cpp
class TreeIterStateMachinePass : public Pass {
  void Run(Function& func) override {
    // 1. 检测模式
    auto yield_froms = detectTreeIterPattern(func);

    // 2. 检查逃逸分析结果（Phase 3.1）
    if (!shouldInline(func, yield_froms)) {
      return;  // 回退
    }

    // 3. 生成状态机
    generateInlineStateMachine(func, yield_froms);
  }

private:
  void generateInlineStateMachine(
      Function& func,
      const std::vector<const YieldFrom*>& yield_froms);

  BasicBlock* generateLeftPhase(Function& func, Register* current, Register* phase);
  BasicBlock* generateYieldPhase(Function& func, Register* current, Register* phase);
  BasicBlock* generateRightPhase(Function& func, Register* current, Register* phase);
  BasicBlock* generateBacktrackPhase(Function& func, Register* current, Register* phase);

  void generateStackPush(Function& func, Register* node, int phase, int stack_offset);
  std::pair<Register*, int> generateStackPop(Function& func, int stack_offset);
};
```

## 数据结构

### Phase 枚举

```cpp
enum class TreeIterPhase : int {
  LEFT = 0,      // 进入左子树
  YIELD = 1,     // 产生当前值
  RIGHT = 2,     // 进入右子树
  BACKTRACK = 3  // 回溯
};
```

### 栈布局（x86_64）

```
调用栈（rsp 向下增长）：
┌─────────────────────┐
│  state.current      │ rsp+0   (8 bytes)
├─────────────────────┤
│  state.phase       │ rsp+8   (1 byte)
├─────────────────────┤
│  padding           │ rsp+9-15
├─────────────────────┤
│  stack[0].node    │ rsp+16  (8 bytes)
├─────────────────────┤
│  stack[0].phase   │ rsp+24  (1 byte)
├─────────────────────┤
│  stack[1].node    │ rsp+32
├─────────────────────┤
│  ...               │
├─────────────────────┤
│  stack[31].phase  │ rsp+264
├─────────────────────┤
│  return address    │ rsp+272
└─────────────────────┘

总计：256 字节
```

## 错误处理

### 边界情况

1. **深度超过限制**：回退到标准生成器路径
2. **空树/空节点**：跳过该分支
3. **内联深度达到限制**：回退到标准 yield-from

### Deoptimization

```cpp
if (!generateInlineStateMachine(func, yield_froms)) {
  rollbackHIRChanges(func);
  for (auto* yf : yield_froms) {
    emit<OptimizedYieldFrom>(yf);
  }
}
```
