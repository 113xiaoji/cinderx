# StackNode.__iter__ HIR (Baseline - Stack-based Iterator)

This file contains the baseline HIR for the stack-based iterator implementation
that avoids recursion by managing an explicit stack.

## Key Features:
- No yield-from (uses explicit stack management)
- Complex control flow with nested conditionals
- Heavy use of method calls (list.append, list.pop)
- Tuple unpacking and multiple local variables

## Analysis:

### Control Flow Complexity:
- 13 basic blocks
- Single main loop with nested conditionals
- No yield-from (simpler generator protocol)

### Key Differences from Recursive Version:
1. **Explicit stack management**: Creates list and manages tuples (bb 12)
2. **Method call overhead**: LoadMethodCached/CallMethod for append/pop (bb 2, bb 4, bb 9)
3. **Tuple unpacking**: Complex type checking and array access (bb 15-19)
4. **No coroutine checks**: Simpler control flow without yield-from safety

### Performance Characteristics:
- More instructions per iteration (method calls, tuple operations)
- Better cache locality (single loop vs recursive calls)
- No yield-from overhead (Send/YieldFrom instructions)
- Heavier register pressure (5 locals vs 1 in recursive)

| Basic blocks | 13 | 15 |
| YieldValue | 1 | 1 |
| YieldFrom | 0 | 2 |
| Method calls | 6 | 0 |
| Phi nodes | 3 | 4 |
