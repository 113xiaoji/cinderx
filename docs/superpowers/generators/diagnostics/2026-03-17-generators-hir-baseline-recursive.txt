# Node.__iter__ HIR (Baseline - Recursive Generator with yield-from)

- Uses `yield from` for recursive iteration (lines 179, 372)
- Send/YieldFrom pattern for delegating to sub-generators
- Type checks for coroutine safety (bb 1, bb 6)

## Analysis:

### Control Flow Complexity:
- 15 basic blocks
- 2 yield-from loops (bb 2-3 for left, bb 7-8 for right)
- Coroutine type checking duplicated for left/right children

### Yield-From Pattern (bb 2-3, bb 7-8):
- `Send` instruction to send value to sub-iterator
- `YieldFrom` instruction to yield value to caller
- Loop continues until sub-iterator exhausted

### Optimization Opportunities:
1. Eliminate duplicate coroutine type checks
2. Inline yield-from loops to reduce Send/YieldFrom overhead
3. Reduce Phi node complexity through better register allocation
