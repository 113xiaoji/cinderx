## TDD 工作流程

### 开发循环

1. **选择一个测试**
   ```python
   # 例如：T1.1 test_no_escape_list
   ```

2. **移除 skipTest，让测试运行**
   ```python
   # self.skipTest("逃逸分析未实现")
   ```

3. **确认测试失败（红）**
   ```
   FAIL: test_no_escape_list
   ```

4. **实现最小代码使测试通过（绿）**
   - 实现 `EscapeAnalysisPass`
   - 检测不可逃逸场景

5. **重构优化**
   - 代码清理
   - 性能优化

6. **重复下一个测试**
